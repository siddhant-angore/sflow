- **In** "`how` over the affected subsystem.": Read the **layered-architecture** skill (or the **flutter-apply-architecture-best-practices** skill when `CLAUDE.md` says `architecture: mvvm`) and run its done-check, a grep that only entrypoints and bootstrap import data packages, to learn where the change belongs.
- **In** "`architect` for parallel design exploration.": Runners read the **bloc** skill for state, the **vgv-navigation** skill for routes, the **material-theming** and **ui-package** skills for widgets and tokens, the **internationalization** skill for strings, the **vgv-accessibility** skill for the WCAG level, the **vgv-animations** skill for motion, and the **flutter-build-responsive-layout** skill for layout. Dart 3 shapes come from the **dart-use-pattern-matching** and **dart-use-primary-constructors** skills.
- **In** "Delegate code-writing to a subagent": The brief names the test seams and points the delegate at the **vgv-testing** skill (`pumpApp`, `TestTag`, `group(Type)`), the Mocking section of the **flutter** skill to pick mocktail or mockito's generated mocks for this package, the `blocTest` section of the **bloc** skill for state tests, the pump decision table in the **flutter-add-widget-test** skill, and the **flutter-add-widget-preview** skill for a new widget. Tests run through the Very Good `test` MCP tool; `flutter test` in Bash is refused by the hook.
- **In** "Verify on the matching surface.": Launch the app with `launch_app`, read `get_runtime_errors` and `get_app_logs`, and apply the hot reload rule from `<flutter>/rules/flutter-hot-reload.md` after each `lib/` edit. Drive a user journey with `flutter_driver_command` and freeze it into `integration_test/` per the **flutter-add-integration-test** skill. Then run the **green-gate** skill until analyze, format, test, and coverage are all observed green in one round; a cached green does not count.
